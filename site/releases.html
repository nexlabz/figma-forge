0.2.0 06 Oct 2026 CURRENT

Artifact import, and line breaks that hold

Made AI-generated artifacts a first-class source, and fixed the thing that quietly ruined text on every build before it.

ADDED
  • Artifact import — one artboard per board, named from the board's own label, at its native export size.
  • Notes columns carried across with the boards they annotate.
  • Marketplace manifest, so it installs with one command instead of a clone.
  • Mixed-size canvases split from a measured rect list, so a sheet where every tile differs builds in one pass.
FIXED
  • Pinned line breaks. Figma's font metrics differ from the browser's, so fixed-width text re-wrapped and overflowed. Breaks are now measured in the browser and written as hard breaks.
  • Emoji no longer split words. Break positions are computed in UTF-16 code units; slicing by code point drifted one place per astral character.
  • Masked icons keep their knockout when the mask lives outside the icon's own <svg>.
0.1.0 28 Sep 2026

First cut

The pipeline end to end: render in headless Chrome, extract computed geometry, build through Figma's Plugin API.

ADDED
  • Live URL and codebase as sources, with section-by-section builds for long pages.
  • Token derivation — colour ramps, type scale, spacing and radii as Figma variables and text styles.
  • Bundled Figma connection, so installing the plugin is the whole setup.
  • Idempotent builds keyed on frame names: a re-run reconciles rather than duplicating.
Known issues  /  eight tracked, three that fail quietly

Worth knowing before you trust a build

These three report success and leave a file that looks finished.

SILENT

A fresh build can undo the line-break fix. The generated runtime gives multi-line text a fixed width even when breaks are pinned, so Figma re-wraps it. Worked around on every run today; the real fix is two lines.

SILENT

Borderless rectangles render as solid grey. A rectangle with no source fill keeps Figma's default #D9D9D9, so outlines and dividers arrive as filled blocks.

SILENT

Cross-root SVG references drop. An icon masked by a definition in another <svg> inlines without it and renders solid. Also empties <use> sprites.

PARTIAL

Text shadows aren't captured, so a CSS extrude arrives flat. Figma also caps drop shadows at eight per node and truncates without warning.

PARTIAL

Repeating gradients flatten to a single band. CSS filters, blend modes and masks don't cross over at all.
