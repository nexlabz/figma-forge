Install  /  about three minutes

Two commands and
one Figma sign-in

No account to create, nothing to upload. It writes straight into a file you already have open.

$ /plugin marketplace add nexlabz/figma-forge

Four things need to be true

  • Claude Code — Figma Forge runs as a plugin inside it.
  • Node — nothing to npm install; the scripts use Node's built-in fetch and WebSocket.
  • Chrome or Chromium on the machine. The extractor drives it over the DevTools Protocol.
  • A Figma Full seat on the team you're writing into. A View or Dev seat can read a file but never build into it.

Add the plugin

One command adds the marketplace, one installs it. The Figma connection comes bundled.

claude code
$ /plugin marketplace add nexlabz/figma-forge
$ /plugin install figma-forge@figma-forge
copy both lines

Sign in to Figma, once

Run /mcp, pick figma, choose Authenticate. It opens Figma in your browser for a one-time approval.

Make sure the browser is already signed in as the account you want — the approval follows whichever session is live there, not whichever you meant.

Point it at something

The file key is the segment after /design/ in your Figma URL.

first import
$ /figma-forge:url-to-figma https://stripe.com
$ /figma-forge:code-to-figma src/app/pricing/page.tsx
$ /figma-forge:artifact-to-figma https://claude.ai/artifact/<id>
copy all three

Turn values into variables

Optional. Once a source is extracted, derive Figma variables and text styles instead of hardcoded fills — colour ramps, type scale, spacing, radii, light and dark.

$ /figma-forge:tokens
Troubleshooting  /  the five real ones

When it doesn't work

CHROME

spawn google-chrome ENOENT. No browser found. Set CHROME_PATH to your Chrome executable.

SEAT

Can't call createPage in read-only mode. The account can read the file but not write. You need edit access and a Full seat — this fails after a clean sign-in, which makes it look like something else.

ACCOUNT

No edit access to this file. Either it isn't shared with the signed-in account, or you're signed in as a different one. Check /mcp before re-sharing anything.

LAYOUT

The page came out reflowed. The capture viewport was narrower than the source's own stage. A board canvas often needs 3000px, not a device width.

CAPTURE

The reference screenshot is black below the fold. Chrome caps full-page capture at 16000px. The extracted design is complete; only the reference image is clipped.
