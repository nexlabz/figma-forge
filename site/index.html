      Roadmap  /  what's coming
      
Where it's going

      

        
SHIPPING
One call, one URL
A single entry point that works out whether it's a board canvas or a page, and builds — no decisions along the way.

        
NEXT
Figma plugin
Import from inside Figma, with a viewport picker and multi-frame output.

        
NEXT
Warnings that mean something
Every quiet translation failure reported as structured output, so a build can be trusted without someone eyeballing it.

        
LATER
Round-tripping
Figma edits flowing back as updated code or tokens. The build is already idempotent by frame name, which is the groundwork.

        
LATER
Design systems, not artboards
Land variables, text styles and components instead of a pile of frames.

        
LATER
Components from repeats
Spot a repeated card or row and build it once as a component with instances.
